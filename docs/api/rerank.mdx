## Endpoint

```text
POST /rerank
```

完整地址：

```text
https://emrank.tech/v1/rerank
```

## 请求头

| Header | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | `Bearer <api_key>` |
| `Content-Type` | 是 | `application/json` |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | `string` | 是 | 重排序模型名称（以控制台模型列表为准） |
| `query` | `string` | 是 | 查询文本 |
| `documents` | `string[]` | 是 | 需要重排的非空列表；也支持含 text、可选 id / metadata 的对象 |
| `top_n` | `number` | 否 | 返回最相关的前 N 条，不得超过文档数量 |
| `return_documents` | `boolean` | 否 | 是否恢复原始文档及元信息，默认 false |
| `instruction` | `string` | 否 | 重排序指令（须由适配器显式声明支持） |
| `max_chunks_per_doc` | `number` | 否 | 长文切分的最大 chunk 数（须由适配器显式声明支持） |
| `overlap_tokens` | `number` | 否 | chunk 之间的 token 重叠（须由适配器显式声明支持） |

请从[模型广场](https://emrank.tech/models)复制完整重排序模型 ID；本站当前不提供独立多模态重排序路由。

:::tip 常见用法
例如：只返回索引/分数（`return_documents: false`）、不同 `top_n` 策略等，见 [代码示例](/guide/examples)。
:::

## 返回体（JSON）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `model` | `string` | 网关公开模型 ID |
| `results` | `Array<{ index: number; relevance_score: number; document?: { text: string } }>` | 重排结果 |
| `usage` | `object` | 可选输入用量统计，不沿用旧站的 id / meta 结构 |

## 请求示例

<Tabs>
  <Tab label="Python（openai SDK，自定义请求）">

```python
from openai import OpenAI
import httpx
import os

client = OpenAI(
    base_url="https://emrank.tech/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

resp = client.post(
    "/rerank",
    cast_to=httpx.Response,
    body={
        "model": "Qwen/Qwen3-Reranker-8B",
        "query": "Apple",
        "documents": ["apple", "banana", "fruit", "vegetable"],
        "top_n": 4,
        "return_documents": True,
        "max_chunks_per_doc": 1024,
        "overlap_tokens": 80,
    },
)

resp.raise_for_status()
print(resp.json())
```

import os

## Cohere 示例（`cohere/rerank-v3.5`）

<Tabs>
  <Tab label="Python（requests）">

```python
import os
import requests

url = "https://emrank.tech/v1/rerank"
headers = {
    "Authorization": f"Bearer {os.environ['OPENAI_API_KEY']}",
    "Content-Type": "application/json",
}
payload = {
    "model": "cohere/rerank-v3.5",
    "query": "Apple",
    "documents": ["apple", "banana", "fruit", "vegetable"],
    "top_n": 2,
    "return_documents": True,
}

response = requests.post(url, headers=headers, json=payload, timeout=60)
response.raise_for_status()
print(response.json())
```

  </Tab>
  <Tab label="JavaScript（fetch）">

```ts
const apiKey = process.env.OPENAI_API_KEY!;

const response = await fetch("https://emrank.tech/v1/rerank", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "cohere/rerank-v3.5",
    query: "Apple",
    documents: ["apple", "banana", "fruit", "vegetable"],
    top_n: 2,
    return_documents: true,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

console.log(await response.json());
```

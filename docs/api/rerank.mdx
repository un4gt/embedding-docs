## Endpoint

```text
POST /rerank
```

完整地址：

```text
https://router.tumuer.me/v1/rerank
```

## 请求头

| Header | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | `Bearer <api_key>` |
| `Content-Type` | 是 | `application/json` |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | `string` | 是 | 重排序模型名称（以控制台模型列表为准） |
| `query` | `string` | 是 | 查询文本 |
| `documents` | `string[]` | 是 | 需要重排的文档列表（目前仅支持字符串数组） |
| `top_n` | `number` | 否 | 返回最相关的前 N 条 |
| `return_documents` | `boolean` | 否 | 是否在结果中返回原始文档文本 |
| `instruction` | `string` | 否 | 重排序指令（部分模型支持） |
| `max_chunks_per_doc` | `number` | 否 | 长文切分的最大 chunk 数（部分模型支持） |
| `overlap_tokens` | `number` | 否 | chunk 之间的 token 重叠（部分模型支持） |

:::tip 常见用法
例如：只返回索引/分数（`return_documents: false`）、不同 `top_n` 策略等，见 [代码示例](/guide/examples)。
:::

## 返回体（JSON）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `string` | 请求 ID |
| `results` | `Array<{ index: number; relevance_score: number; document?: { text: string } }>` | 重排结果 |
| `meta` | `object[]` | 元信息（如 tokens 统计） |

## 请求示例

<Tabs>
  <Tab label="Python（openai SDK，自定义请求）">

```python
from openai import OpenAI
import httpx
import os

client = OpenAI(
    base_url="https://router.tumuer.me/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

resp = client.post(
    "/rerank",
    cast_to=httpx.Response,
    body={
        "model": "Pro/BAAI/bge-reranker-v2-m3",
        "query": "Apple",
        "documents": ["apple", "banana", "fruit", "vegetable"],
        "top_n": 4,
        "return_documents": True,
        "max_chunks_per_doc": 1024,
        "overlap_tokens": 80,
    },
)

resp.raise_for_status()
print(resp.json())
```

```python
import os
import requests

url = "https://router.tumuer.me/v1/rerank"
headers = {
    "Authorization": f"Bearer {os.environ['OPENAI_API_KEY']}",
    "Content-Type": "application/json",
}
payload = {
    "model": "Pro/BAAI/bge-reranker-v2-m3",
    "query": "Apple",
    "documents": ["apple", "banana", "fruit", "vegetable"],
    "top_n": 4,
    "return_documents": True,
}

response = requests.post(url, headers=headers, json=payload, timeout=60)
response.raise_for_status()
print(response.json())
```

## Base URL

```text
https://emrank.tech/v1
```

## 鉴权

所有请求使用 `Authorization` 请求头：

```text
Authorization: Bearer <api_key>
```

## 端点

- [POST /embeddings：创建嵌入请求](/api/embeddings)
- [POST /rerank：创建重排序请求](/api/rerank)


- [POST /decisions：创建决策请求](/api/decisions)
- [Gemini 文本嵌入](/api/gemini)

`POST /v1/decision` 是决策接口的单数别名；`GET /v1/models` 返回可路由的公开模型，也需要 API 令牌。

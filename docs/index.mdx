## 服务地址

OpenAI SDK 和兼容客户端的 Base URL：

```text
https://emrank.tech/v1
```

直接 HTTP 调用使用完整路径 `/v1/embeddings`、`/v1/rerank` 或 `/v1/decisions`。Gemini 兼容入口位于 `/v1beta`。

在[主站控制台](https://emrank.tech/)登录并创建自己的 API 令牌，再从[模型广场](https://emrank.tech/models)复制完整可用模型 ID。厂商密钥由渠道管理，不应填入客户端。

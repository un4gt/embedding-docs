---
title: RAGFlow：在 RAGFlow 中使用
description: 将 Embedding Provider 指向 OpenAI-API-Compatible。
---

1. 在 RAGFlow 的模型配置中新增 Embedding 模型，Provider 选择 **OpenAI-API-Compatible**（或 **OpenAI Compatible**）。
2. **基础 Url** 填 `https://emrank.tech/v1`；**API-Key** 填控制台生成的 Key。
3. **模型名称** 填任意模型（推荐 `Qwen/Qwen3-Embedding-8B`），其余参数按需填写即可。

![RAGFlow 配置示例：选择 OpenAI-API-Compatible，填写模型类型、模型名称、基础 Url 与 API-Key](/use_with_ragflow.png)


截图仅用于说明配置位置，旧地址和模型名不要照抄。请使用 `https://emrank.tech/v1`、本站 API 令牌及[模型广场](https://emrank.tech/models)中的完整可用模型 ID。

description: 在 AstrBot WebUI 中配置 Embedding Provider。

1. 导航至 AstrBot WebUI 的「模型提供商」。
2. 按下图选择「嵌入」：
   ![选择 OpenAI embedding](/select_openai_embedding_for_astrbot.png)
3. 分别填入 API Key、Base URL 和模型名称：
   ![填入相关参数](/save_embedding_provider_for_astrbot.png)


截图仅用于说明配置位置，旧地址和模型名不要照抄。请使用 `https://emrank.tech/v1`、本站 API 令牌及[模型广场](https://emrank.tech/models)中的完整可用模型 ID。

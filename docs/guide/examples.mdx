## SDK 初始化（OpenAI Compatible）

SDK 调用与 OpenAI 官方一致，只需要把 `base_url`（或 `baseURL`）改为 `https://router.tumuer.me/v1`，并填入控制台生成的 `api_key`。

<Tabs>
  <Tab label="Python">

```python
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://router.tumuer.me/v1",
    api_key=os.environ["OPENAI_API_KEY"],  # 在控制台生成
)
```

  </Tab>
  <Tab label="JavaScript">

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://router.tumuer.me/v1",
  apiKey: process.env.OPENAI_API_KEY, // 在控制台生成
});
```

## Embeddings：常见用法

### 批量向量化（一次请求多条 input）

<Tabs>
  <Tab label="Python（openai SDK）">

```python
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://router.tumuer.me/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

response = client.embeddings.create(
    model="Qwen/Qwen3-Embedding-4B",
    input=["第一段文本", "第二段文本"],
    encoding_format="float",
)

print("count:", len(response.data))
print("dim:", len(response.data[0].embedding))
```

  </Tab>
  <Tab label="JavaScript（openai SDK）">

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://router.tumuer.me/v1",
  apiKey: process.env.OPENAI_API_KEY,
});

const response = await client.embeddings.create({
  model: "Qwen/Qwen3-Embedding-4B",
  input: ["第一段文本", "第二段文本"],
  encoding_format: "float",
});

console.log("count:", response.data.length);
console.log("dim:", response.data[0].embedding.length);
```

  </Tab>
</Tabs>

### 多模态 Embedding（图像 URL / data URL）

`jina-clip-v1` / `jina-clip-v2` / `Qwen3-VL-Embedding-*` / `nvidia/nv-dinov2` 可通过 `/embeddings` 调用。推荐传可访问的图片 URL，或 `data:image/...;base64,...` 字符串。

<Tabs>
  <Tab label="Python（requests）">

```python
import os
import requests

url = "https://router.tumuer.me/v1/embeddings"
headers = {
    "Authorization": f"Bearer {os.environ['OPENAI_API_KEY']}",
    "Content-Type": "application/json",
}

payload = {
    "model": "jina-clip-v2",
    "input": "https://example.com/cat.png",
}

resp = requests.post(url, headers=headers, json=payload, timeout=60)
resp.raise_for_status()
data = resp.json()

print("dim:", len(data["data"][0]["embedding"]))
```

  </Tab>
  <Tab label="JavaScript（fetch）">

```ts
const apiKey = process.env.OPENAI_API_KEY!;

const response = await fetch("https://router.tumuer.me/v1/embeddings", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "nvidia/nv-dinov2",
    input: "https://example.com/cat.png",
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const result = await response.json();
console.log("dim:", result.data[0].embedding.length);
```

  </Tab>

```bash
curl "https://router.tumuer.me/v1/embeddings" \
```

## Rerank：常见用法

`/rerank` 不是 OpenAI 标准端点；如果你仍想复用 OpenAI SDK 的鉴权与 baseURL 配置，可以用 SDK 的“自定义请求”能力直接 `POST /rerank`（完整示例见 [创建重排序请求](/api/rerank)）。

<Tabs>
  <Tab label="Python（openai SDK，自定义请求）">

```python
from openai import OpenAI
import httpx
import os

client = OpenAI(
    base_url="https://router.tumuer.me/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

resp = client.post(
    "/rerank",
    cast_to=httpx.Response,
    body={
        "model": "Pro/BAAI/bge-reranker-v2-m3",
        "query": "Apple",
        "documents": ["apple", "banana", "fruit", "vegetable"],
        "top_n": 10,
        "return_documents": False,
    },
)

resp.raise_for_status()
print(resp.json())
```

  </Tab>
  <Tab label="JavaScript（openai SDK，自定义请求）">

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://router.tumuer.me/v1",
  apiKey: process.env.OPENAI_API_KEY,
});

const result = await client.post("/rerank", {
  body: {
    model: "Pro/BAAI/bge-reranker-v2-m3",
    query: "Apple",
    documents: ["apple", "banana", "fruit", "vegetable"],
    top_n: 10,
    return_documents: false,
  },
});

console.log(result);
```

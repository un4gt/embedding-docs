## 查看实时目录

打开[EMRank 模型广场](https://emrank.tech/models)，查看当前公开模型 ID、类型、可用状态、输入倍率，以及已知的上下文和发布日期。目录可匿名浏览；目录中存在但标记不可用的模型不能用于推理。

文档不维护第二份固定模型清单，以免渠道和倍率调整后过期。需要自动获取可路由模型时：

```bash
curl https://emrank.tech/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"
```

该接口必须携带本站推理 API 令牌。使用响应 `data[].id` 的完整值，不要截取最后一段名称。列表反映启用路由，不保证某个上游始终健康或当前密钥配额充足。

## 选择模型类型

| 类型 | 入口 | 用途 |
| --- | --- | --- |
| 向量嵌入 | `/v1/embeddings` | 文本向量、语义检索与知识库 |
| 重排序 | `/v1/rerank` | 对召回文档进行相关性排序 |
| 决策 | `/v1/decisions`，别名 `/v1/decision` | 判断、分类与评分 |

文档中的示例 ID 需要结合当前目录确认，不能据此推断所有模型都已启用。公共 ID 统一使用作者/模型名，与供应商无关，详见[完整模型 ID 规则](/guide/model-ids)。

## 维度与索引

先发送一次向量请求并确认实际向量长度，再创建索引；`dimensions` 需模型和适配器支持。写入文档与查询时应使用相同模型和维度。更换模型或维度后应重新生成文档向量，不能混用不同模型的向量。

模型可用性查看主站目录，运行状态参考[状态检测](https://status.emrank.tech/)，费用规则见[计费与额度](/guide/billing)。

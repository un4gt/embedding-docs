:::tip OpenAI 兼容
向量嵌入兼容 OpenAI SDK；重排序使用 `/v1/rerank`，决策使用独立 System One 协议。
:::

## 1) 配置 Base URL

统一使用：

```text
https://emrank.tech/v1
```

注意：这里已包含 `/v1`，因此 `POST /embeddings` 的完整地址为 `https://emrank.tech/v1/embeddings`。

## 2) 获取并保存 API Key

从本站控制台“令牌管理”生成 API 令牌，建议保存为环境变量：`OPENAI_API_KEY`。

## 3) 选择模型

从[模型广场](https://emrank.tech/models)复制一个可用向量模型的完整 ID。以下使用 `Qwen/Qwen3-Embedding-8B` 示例，请先确认当前可用状态。

## 4) 发送一次 Embeddings 请求

```bash
curl "https://emrank.tech/v1/embeddings" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-Embedding-8B",
    "input": "这是一段需要转换成向量的文本",
    "encoding_format": "float"
  }'
```

title: 快速开始
description: 用最少的配置调用 /embeddings 与 /rerank。
---

:::tip OpenAI 兼容
SDK / HTTP 调用方式与 OpenAI 官方接口一致，只需替换 `base_url` 与 `api_key`。
:::

## 1) 配置 Base URL

统一使用：

```text
https://router.tumuer.me/v1
```

注意：这里已包含 `/v1`，因此 `POST /embeddings` 的完整地址为 `https://router.tumuer.me/v1/embeddings`。

## 2) 获取并保存 API Key

从控制台生成 `api_key`，建议保存为环境变量：`OPENAI_API_KEY`。

## 3) 选择模型

从 [可用模型](/guide/models) 中选择其一；通用推荐 `Qwen/Qwen3-Embedding-4B`。

## 4) 发送一次 Embeddings 请求

```bash
curl "https://router.tumuer.me/v1/embeddings" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-Embedding-4B",
    "input": "这是一段需要转换成向量的文本",
    "encoding_format": "float"
  }'
```

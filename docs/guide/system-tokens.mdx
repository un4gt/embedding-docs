---
title: 系统访问令牌
description: 外部程序调用管理接口的凭据，与模型推理 API 令牌分开。
---

在[个人中心](https://emrank.tech/account)生成、重置或撤销“系统访问令牌”。新令牌只在生成时显示一次，请妥善保存；重置或撤销后旧令牌立即失效。

管理请求使用 `Authorization: Bearer <系统访问令牌>`，权限始终取决于账号当前角色和状态。它不能调用模型推理接口；推理 API 令牌也不能授权管理操作。

```bash
curl https://emrank.tech/api/models/ \
  -H "Authorization: Bearer $EMRANK_SYSTEM_TOKEN"
```

支持现有用户、模型、渠道、日志、兑换码和系统配置管理接口，但不提升账号权限或改变数据归属限制。普通用户仅能访问自己有权查看的资源；兑换码管理需要超级管理员。

个人 API 令牌管理、修改密码、签到和系统访问令牌自身的生成 / 重置 / 撤销仍需网页登录。已验证的 Bearer 管理请求不需要浏览器 CSRF 头。

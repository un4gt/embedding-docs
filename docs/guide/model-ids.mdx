title: 公共模型 ID 规则
description: 作者命名、多渠道选择、固定默认维度与版本选择。

## 用户只选择模型

公共模型 ID 使用 `作者/模型名`，例如 `Qwen/Qwen3-Embedding-8B`、`openai/text-embedding-3-small`。作者命名空间不指定托管渠道；无需填写 Nebius、Featherless、Azure 等供应商名称。

从[模型广场](https://emrank.tech/models)复制 ID，或携带本站 API 令牌调用 `GET https://emrank.tech/v1/models`。`model` 精确匹配，包括大小写和版本；不会根据最后一段名称猜测。

## 多渠道如何选择

一个公共模型可关联多个供应商。网关先按请求的维度、输入类型等能力筛选，然后按优先级、同级权重及健康状态选择渠道。可重试失败在请求总预算内故障转移，上游收到该渠道配置的模型代码。

例如 `Qwen/Qwen3-Embedding-8B` 可由多个供应商服务。请求 `dimensions: 1536` 时，不支持该维度的渠道会被排除。供应商不会因为名称相似自动加入某个公共模型；关联由管理员明确配置。

一个公共模型只有一个对外倍率，请求接入时固定。换渠道不改变该请求的倍率，不重复扣费。本站不提供通过供应商前缀锁定渠道的调用方式。

## 固定默认维度

模型列表的 `default_dimensions` 是省略 `dimensions` 时使用的固定值，`supported_dimensions` 是已启用关联声明支持的维度并集。默认值可提供时位于支持列表首项。优先级、权重及健康变化不改变默认输出长度。

如果固定默认值暂时没有兼容渠道，省略维度的请求会明确失败，不自动改为另一维度。可显式请求仍有兼容渠道的其他维度。渠道整体不健康或密钥配额不足也可能导致请求失败，能力列表不保证实时可用。

## 固定版本与 latest

`typesafe/jev-latest` 对应上游 `jev-latest`，可能随发布升级。`typesafe/jev-1.14.0` 与 `typesafe/jev-1.13.0` 分别固定版本，不互相替换，也不回退到 latest。

## 旧名称切换

统一命名上线时一次切换旧 ID，不保留全局重定向或隐藏别名。原 `nebius/Qwen/Qwen3-Embedding-8B`、`featherless/Qwen/Qwen3-Embedding-8B` 等供应商名称停用；原 `text-embedding-3-small` 改为 `openai/text-embedding-3-small`。请从实时目录复制新 ID 更新客户端，旧名返回 `404 model_not_found`。

历史日志与账单保留当时的请求名称和金额。排障时保留响应的 `X-Request-ID`。
